OPERASIONAL AKSES

Lounge/Tenant Access

Scan dan verifikasi boarding pass menggunakan kamera smartphone, scanner USB/Bluetooth, string code, QR, atau input manual.

STEP 01

Scan Boarding Pass

Parser membaca nama, rute, flight, cabin, seat, sequence, ticket number, dan indicator eligibility.

Scanner Ready
Kamera belum aktif.
Scanner eksternal: scanner USB/Bluetooth yang bekerja sebagai keyboard tidak perlu mengaktifkan kamera. Arahkan ke field di atas dan scanner akan diproses otomatis saat mengirim Enter.
Kamera: menggunakan ZXing cross-browser bila tersedia, dengan fallback BarcodeDetector browser. Format utama: PDF417, QR, Aztec, Data Matrix, Code 128/EAN.
⌁
Menunggu Boarding Pass Data hasil parsing dan status eligibility akan tampil di sini.
FALLBACK

Input Manual

Digunakan bila barcode/string tidak dapat dibaca. Eligibility tidak diisi manual.

Eligibility manual dihitung otomatis: Cabin C/Business = Eligible. Cabin Y/Economy = Eligible untuk Platinum atau Elite Plus; kombinasi lain = Tidak Eligible.
